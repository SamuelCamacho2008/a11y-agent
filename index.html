A11y Agent — Test de Accesibilidad

Auditoría en línea de accesibilidad web (WCAG 2.1 / 2.2) y aplicaciones móviles Android (EN 301 549). Inspirado en el Modelo TAW con motor determinista axe-core y remediación de código interactiva.

Auditar Página Web en Línea

Ingrese la URL pública para analizarla con el motor formal axe-core según los 4 principios WCAG.

Auditar Código HTML Directo

Pegue código HTML crudo o cargue un archivo .html para evaluarlo instantáneamente en el navegador sin restricciones CORS.

Auditoría de Aplicaciones Android (.APK)

Suelte un archivo .apk para inspeccionar layouts XML, descripciones accesibles (contentDescription), tamaños táctiles (48x48dp) y TalkBack.

📱
Haga clic o arrastre un archivo .APK aquí

El análisis se realiza 100% en su navegador mediante JSZip (no se sube a ningún servidor externo).
